# SnapEat

SnapEat is a mobile food ordering application developed using C#.
The application simplifies the food ordering process for both customers and restaurant staff by providing an intuitive ordering experience and an efficient backend management system.

📱 Features

1. Customer Features

- Browse available menus
- View food items and pricing
- Place food orders
- Track order status in real time

2. Restaurant Staff Features

- View and manage incoming orders
- Update order statuses
- Manage menu items and availability
- Streamlined backend interface for daily operations

🛠️ Tech Stack

- Language: C#
- Framework: .NET
- Platform: Mobile / Web
- Backend: SQL Server

🎯 Project Objective

- Improve efficiency in food ordering workflows
- Reduce manual order handling
- Enhance communication between customers and restaurant staff
- Provide a scalable foundation for digital food ordering systems
